# Snippets

Variant-specific resources copied into variant Docker images via COPY instructions. These are not shared across all images — shared infrastructure (apt packages, Serena, cli-tools, codeuser setup) lives in `Dockerfile.base`. This directory holds only resources that belong to one or two variants.

## Directory Layout

- `shared/` holds two groups. Binary helpers (dis16.sh, r216.sh, dump16.sh) are used by both `Dockerfile.snes` and `Dockerfile.x86`. Java toolchain install scripts are used by the JDK-bearing variants: `install-jdk.sh` by java, java-docker, java-angular, x86, snes, 68k and kicad; `install-jdtls.sh` and `install-lombok.sh` by the three java variants. `install-ghidra.sh` is used by x86, snes and 68k and `install-rea.sh` by x86 and 68k; their pins are the `x-ghidra-toolchain` and `x-rea-toolchain` anchors in docker-compose.yml. Sharing rule: a Dockerfile step that two or more variants run identically lives here as a script taking its pins as arguments, so pins stay in docker-compose.yml or the variant Dockerfile ARG defaults while the script owns the URL templates and the procedure exists once. Dockerfiles COPY the scripts into the image at `/usr/local/share/claude-env/install/` and run them with bash. Argument contract: arguments are positional, with a fixed count and order per script: `install-jdk.sh <java_lang_version> <adoptium_version> <adoptium_build>`, `install-jdtls.sh <jdtls_version> <jdtls_timestamp>`, `install-lombok.sh <lombok_version> <lombok_sha256>`, `install-ghidra.sh <ghidra_version> <ghidra_date> <ghidra_sha256>`, `install-rea.sh <rea_version>`. A wrong count or an empty argument prints a usage line to stderr and exits 2, so an unset compose/ARG pin fails the build instead of producing a malformed URL. Dockerfiles invoke `bash <script>` rather than executing the file directly because the executable bit that COPY preserves depends on the checkout and host file mode (it can be lost on some hosts or filesystems), and a chmod layer would add cost for no gain.
- `snes/` resources are specific to the SNES analysis variant only.
