# claude-env container toolchain: 68k

## Tools (68k)

| Tool | What | Use when |
| --- | --- | --- |
| `vasmm68k_mot` | 68000 assembler, Motorola syntax | Assembling 68000/Neo Geo code |
| `vasmz80_mot` | Z80 assembler | Assembling Z80 code |
| `vlink` | Linker for vasm output | Linking assembled object files |
| `mame` | Emulator for Neo Geo / 68k targets (/usr/games) | Running or debugging a built ROM |

## Environment (68k)

| Variable | What |
| --- | --- |
| `VARIANT` | Container variant name (`68k`) |

## Notes (68k)

- Serena has no assembler language server; `.asm` files are not indexed (Python/Go/Rust/TS helper scripts are).
- MAME runs headless-only here (no display); use it for automated runs and debugger scripts.
- Presence on PATH is what the build verifies; it does not guarantee a listed tool succeeds for every invocation.
